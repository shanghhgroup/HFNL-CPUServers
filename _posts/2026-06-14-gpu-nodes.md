## 1. 说明

本计算服务器，是CPU计算服务器，不含GPU资源。

## 2. 没有 GPU 资源怎么办？

当前可用服务器没有 GPU 资源，仍可运行：

- CPU 版本的预处理和后处理脚本；
- 小规模模型调试；
- 不依赖 CUDA 的科学计算程序；
- 使用 CPU 后端的 PyTorch / NumPy / SciPy 程序；
- 将训练任务转移到组内其他 GPU 服务器或合作平台。

## 3. 常见检查命令

登录后可根据内部规则使用下面命令检查环境。公开页面不展示实际输出。

```bash
nvidia-smi
sinfo
squeue -u $USER
```
