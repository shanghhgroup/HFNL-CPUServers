## 0. 服务器简介

本页面用于介绍 ShangGroup 实验室HFNL CPU计算服务器的基本用途、使用流程、作业提交方式和注意事项。

该服务器面向科研计算任务，主要服务于量子化学、量子蒙特卡洛、数值模拟、程序编译测试、科研数据处理和结果后处理等工作。页面只介绍服务器的基本功能和通用操作方法；具体登录地址、节点名称、硬件型号、存储路径、网络配置和管理员联系方式请通过实验室内部渠道获取。



## 1. 服务器总览

| 项目 | 公开说明 |
|---|---|
| 服务器定位 | 实验室科研计算服务器 |
| 主要用途 | 量子化学、AFQMC/QMC、数值模拟、代码编译、数据处理 |
| 计算资源 | 以 CPU 科学计算资源为主，具体规格以内部通知为准 |
| 作业管理 | 使用 Slurm 作业调度系统统一提交和管理任务 |
| 运行环境 | Linux 科研计算环境 |
| 数据空间 | 提供科研数据存放空间，具体路径以内部说明为准 |
| 访问方式 | 通过实验室内部提供的 SSH / VPN / 跳板机方式访问 |
| 公开范围 | 本页只介绍通用流程，不公开内部配置细节 |

## 2. 服务器组成

| 类型 | 公开说明 | 主要用途 |
|---|---|---|
| 登录环境 | 用于登录、编辑脚本、整理文件和提交作业 | 轻量操作、任务准备、日志查看 |
| CPU 计算资源 | 面向多核 CPU 科学计算任务 | 量子化学、QMC、数值模拟、数据分析 |
| 作业调度系统 | 统一管理用户提交的计算任务 | 排队、分配资源、记录日志 |
| 数据存储空间 | 用于保存输入文件、输出结果和中间数据 | 项目数据管理和结果归档 |
| 公共软件环境 | 根据实验室需求配置或由用户自行维护 | 编译、Python、MPI、科学计算库等 |

## 3. 适合运行的任务

适合：

- CPU 并行程序；
- 量子化学与电子结构计算；
- AFQMC / QMC 类科研任务；
- Python / C++ / Fortran 科研程序；
- 中小规模 MPI 或 OpenMP 程序；
- 数据预处理、后处理和绘图脚本；
- 需要规范记录日志和结果的批量计算任务。

需要提前确认：

- GPU / CUDA 任务；
- 长时间大规模占用资源的任务；
- 多节点强通信 MPI 任务；
- 大规模并行 I/O 或高频写入共享文件系统的任务；
- 需要管理员安装系统级依赖的软件。

## 4. 使用流程

1. 向实验室服务器管理员申请账号；
2. 通过内部渠道获取登录方式、使用规则和初始说明；
3. 使用 SSH 或指定方式登录服务器；
4. 在个人目录或指定数据目录中准备代码和输入文件；
5. 编写 Slurm 作业脚本；
6. 使用 `sbatch` 提交任务；
7. 使用 `squeue -u $USER` 查看任务状态；
8. 任务结束后检查 `.log` 和 `.err` 文件；
9. 整理结果并及时备份重要数据。

## 5. 重要原则

- 不要在登录环境中直接运行大型计算任务；
- 大型任务应通过 Slurm 作业调度系统提交；
- 不要公开服务器地址、端口、跳板机、账号、密码和内部路径；
- 不要删除公共软件、公共数据或他人目录；
- 大文件读写应遵守实验室数据管理规范；
- 新程序先小规模测试，再扩大资源申请；
- 任务异常、长时间无输出或资源占用异常时，应及时检查并联系管理员。
