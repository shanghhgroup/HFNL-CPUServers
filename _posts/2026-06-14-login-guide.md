## 1. 账号申请

如需使用实验室服务器，请通过实验室内部渠道向管理员申请账号。申请时建议说明：

- 姓名；
- 主要计算任务类型；
- 预计使用的 CPU、内存、存储和运行时间；
- 是否需要 GPU 或特殊软件环境；
- 是否需要安装额外依赖。

本网页不提供管理员个人联系方式、服务器地址、端口、跳板机、VPN 和密码信息。

## 2. 登录方式

使用本服务器，需先登录跳板机，在跳板机上通过 SSH 或实验室指定的远程访问方式登录。

通用登录格式：

```bash
ssh 用户名@服务器地址
```

关于跳板机信息，请联系管理员或按照实验室内部说明操作。

## 3. 登录后可以做什么

| 操作 | 是否适合在登录环境完成 | 说明 |
|---|---|---|
| 编辑代码和脚本 | 适合 | 可使用 Vim、Nano、VS Code Remote SSH 等工具 |
| 查看日志和小文件 | 适合 | 如 `tail`、`less`、`grep` |
| 编译小程序 | 通常可以 | 大规模编译建议避开高峰或提交作业 |
| 运行短测试 | 谨慎 | 仅限很小规模、很短时间测试 |
| 长时间大计算 | 不适合 | 应通过 Slurm 提交到计算资源 |

## 4. Windows 推荐工具

| 工具 | 用途 |
|---|---|
| Xshell | SSH 登录 |
| Xftp | 文件传输 |
| MobaXterm | SSH 与文件传输一体化 |
| Windows Terminal | 命令行 SSH |
| VS Code Remote SSH | 远程编辑代码 |

## 5. 文件传输

从本地上传文件到服务器：

```bash
scp 本地文件 用户名@服务器地址:/目标路径
```

从服务器下载文件到本地：

```bash
scp 用户名@服务器地址:/远程文件 本地目录
```

如果使用 Xftp 或 MobaXterm，主机地址、端口和用户名应与 SSH 登录信息保持一致。不要在公开文档中保存真实地址和密码。

## 6. 登录后建议先做的检查

```bash
hostname
whoami
pwd
sinfo
squeue -u $USER
df -h
```

这些命令可以帮助你确认登录位置、当前可用分区、自己的任务状态以及磁盘空间情况。公开交流时请注意遮挡主机名、内部路径和其他敏感输出。

## 7. 登录后不要做什么

- 不要在登录环境直接运行大规模计算；
- 不要随意删除公共目录或他人目录；
- 不要把大型临时文件长期堆在系统盘或公共目录；
- 不要共享自己的账号和密码；
- 不要在公开网页、社交平台、论文附录或截图中暴露服务器真实地址、端口、账号、密码和内部路径。
